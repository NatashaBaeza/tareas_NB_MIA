# Ejercicio 01 — Aplicaciones de IA que uso o he usado

1. **Galaxy AI**  
   **Uso**: Eliminación de personas /objetos en imágenes, suprimir ruido en grabaciones de vídeo, por ejemplo se usó para eliminar ruido de tráfico de una avenida en una entrevista que grabé

2. **Canva AI**  
   **Uso**: Creación de imagen publicitaria con información de paqueter de una agencia de viajes, ejemplo lo usé para mostrar e una imagen rápida las fotos de los hoteles y precios de promociones de la Riviera Maya y publicarlo en redes sociales

3. **Extensión de Abacus en VS Code utilizando el modelo Kimi K 2.7 Code**  
   **Uso**: La herramienta Abacus lo he utilizado para varios aplicativos, sin embargo el más reciente fue con ese modelo para editar la interfaz de una aplicación realizada con vibe coding y agregar nuevas funcionalidades

4. **CapCut**  
   **Uso**: Generación de subtítulos automáticos y traducción en idioma inglés para un vídeo de un aplicativo

5. **Aplicación DJI**  
   **Uso**: Elminación del selfieStick en la grabación de una cámara de acción, con la herramienta permite borrarlo para que no aparezca en los vídeos generando el efecto de que alguien te grabó
